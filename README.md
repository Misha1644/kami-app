# Kami — школьный испанский

Приложение для иностранных школьников в Испании: готовит к завтрашним урокам на испанском.
Учит предметные слова по программе (математика, биология и т. д.), объясняет задания учителя
и показывает родителям прогресс. Талисман — хамелеон Ками.

## Что уже есть (версия 0.1)

- **Главная** — темы завтрашних уроков и сколько слов выучено.
- **Урок** — карточка слова с фразой учителя, затем проверка с выбором ответа.
- **Разбор задания** — пока пример; распознавание фото — следующий этап.
- **Родителям** — прогресс ученика по темам.
- Контент: 1º ESO, «Las fracciones» и «La célula» (`src/data/content.js`).
- Вход родителя (email и пароль) и профиль ученика (псевдоним, родной язык).
- База Supabase (проект `kami`, регион Париж): темы, слова, прогресс, серия дней.
  Схема — `supabase/schema.sql`. Если база недоступна, приложение берёт слова из `src/data/content.js`.

## Как запустить

После регистрации Supabase присылает письмо для подтверждения email — откройте ссылку, потом войдите.


**Самый простой способ — Expo Snack (без установки):**
1. Откройте https://snack.expo.dev
2. Меню проекта → **Import git repository** → вставьте ссылку на этот репозиторий.
3. Откройте на телефоне через приложение **Expo Go**.

**На компьютере** (нужен Node.js):
```
npm install
npx expo install --fix
npx expo start
```
и отсканируйте QR-код в Expo Go.

## Структура

```
App.js                    навигация по вкладкам и общий прогресс
src/theme.js              цвета и скругления
src/components/Kami.js    хамелеон Ками
src/components/ui.js      кнопки, карточки, полоса прогресса
src/screens/              экраны
src/data/content.js       запасной учебный контент
src/lib/supabase.js       подключение к базе (только публичный ключ)
src/lib/api.js            все запросы к базе
supabase/schema.sql       таблицы и права доступа
```

## Принципы

- Аккаунт заводит родитель; о ребёнке храним минимум (псевдоним, класс, родной язык).
- Пользователи не общаются между собой.
- Приложение объясняет задание, но не решает его за ученика.
