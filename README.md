# Kami — школьный испанский

Приложение для иностранных школьников в Испании: готовит к завтрашним урокам на испанском.
Учит предметные слова по программе (математика, биология и т. д.), объясняет задания учителя
и показывает родителям прогресс. Талисман — хамелеон Ками.

## Что уже есть (версия 0.1)

- **Главная** — темы завтрашних уроков и сколько слов выучено.
- **Урок** — карточка слова с фразой учителя, затем проверка с выбором ответа.
- **Разбор задания** — пока пример; распознавание фото — следующий этап.
- **Родителям** — прогресс ученика по темам.
- Контент: 1º ESO, «Las fracciones» и «La célula» (`src/data/content.js`).
- Вход родителя (email и пароль) и профиль ученика (псевдоним, родной язык).
- База Supabase (проект `kami`, регион Париж): темы, слова, прогресс, серия дней.
  Схема — `supabase/schema.sql`. Если база недоступна, приложение берёт слова из `src/data/content.js`.

## Версия 0.3

- **Серия дней** как в Duolingo: огонёк, неделя, цель дня (10 слов). Заморозка спасает серию при пропуске.
- **Монеты**: +1 за верное слово, +10 за цель дня. Начисляются только в базе (функции `record_answer`, `buy_item`), накрутить из приложения нельзя.
- **Магазин**: заморозки серии (до 2) и цвета Ками.
- **Расписание**: уроки по дням; главная готовит к предметам следующего учебного дня.
- Миграции базы: `supabase/migrations/`.

## Версия 0.4–0.5

- **Свои предметы** в расписании (хранятся как `x:Название`).
- **Свои слова** к любому предмету: испанское слово, перевод и пример. Учатся в обычном уроке;
  монета — один раз, когда слово выучено впервые (`record_custom_answer`), верные ответы идут в цель дня и серию.

## Версия 0.6

- **Разбор задания по фото или файлу** (камера, галерея, PDF): Edge Function `supabase/functions/explain-task`
  отправляет файл в Claude API (`claude-haiku-5-5`) и возвращает текст задания, объяснение на родном языке,
  ключевые слова и начало ответа — без решения. Лимит 15 разборов в день (`use_task_quota`). Файлы не сохраняются.
  Нужен секрет `ANTHROPIC_API_KEY` в Supabase. Ключевые слова можно сохранить в «Мои слова».
- В магазине «Алмазный Ками» за 100 000 монет.

## Версия 0.7–0.8

- Серия засчитывается за **пройденный урок** (`complete_lesson`), а не за отдельный ответ.
- **Ками Плюс** (таблица `parent_plans`, пишет только сервер): 15 разборов фото в день вместо 3,
  свои слова без лимита (вместо 50), цвет «Ками Плюс», трудные слова в отчёте. Оплата — позже, в версии из сторов.
- Цены: синий Ками 100 (≈5 дней), фиолетовый/коралловый 500, золотой 1 500, алмазный 100 000, заморозка 50.

## Как запустить

После регистрации Supabase присылает письмо для подтверждения email — откройте ссылку, потом войдите.


**Expo Snack (без установки):** импорт из GitHub в Snack сейчас не работает, поэтому
`python3 scripts/build_snack.py` собирает всё приложение в один файл `dist-snack/App.js`.
Его содержимое вставляется в App.js на snack.expo.dev, зависимости — из package.json (без url-polyfill).

**На компьютере** (нужен Node.js):
```
npm install
npx expo install --fix
npx expo start
```
и отсканируйте QR-код в Expo Go.

## Структура

```
App.js                    навигация по вкладкам и общий прогресс
src/theme.js              цвета и скругления
src/components/Kami.js    хамелеон Ками
src/components/ui.js      кнопки, карточки, полоса прогресса
src/screens/              экраны
src/data/content.js       запасной учебный контент
src/lib/supabase.js       подключение к базе (только публичный ключ)
src/lib/api.js            все запросы к базе
supabase/schema.sql       таблицы и права доступа
```

## Принципы

- Аккаунт заводит родитель; о ребёнке храним минимум (псевдоним, класс, родной язык).
- Пользователи не общаются между собой.
- Приложение объясняет задание, но не решает его за ученика.
